## Problem Statement

实验人员在左侧长参数表中编辑样本和基因时，误删一行会丢失已输入内容，且现有顺序无法通过拖动调整。页面在宽屏上使用统一的页面滚动，当左侧参数或右侧反应计算器较长时，中间孔板状态会离开视野，不利于边填写边核对。

## Solution

将左侧样本与基因列表纳入参数编辑历史，支持 Command/Ctrl+Z 撤销和 Shift+Command/Ctrl+Z 重做。为每行添加明确的拖动手柄和键盘排序操作，以可见顺序作为后续排板顺序。在足够宽的桌面视口中，左侧参数区、中间板布局区和右侧反应计算区使用独立滚动容器，使当前孔板始终可见。平板和手机继续使用单列自然滚动。

## User Stories

1. As an 实验人员, I want 误删样本后使用 Command/Ctrl+Z 恢复, so that 我不必重新输入样本信息。
2. As an 实验人员, I want 误删基因后使用 Command/Ctrl+Z 恢复, so that 目的基因与内参设定不会丢失。
3. As an 实验人员, I want 清空列表后仍可撤销, so that 高风险批量操作可以恢复。
4. As an 实验人员, I want 重做刚被撤销的参数操作, so that 我可以在两个状态之间安全比较。
5. As an 实验人员, I want 在文本输入框内保留原生文字撤销, so that 全局快捷键不会破坏正在输入的内容。
6. As an 实验人员, I want 参数历史与孔位手动编辑历史分开, so that 撤销的对象符合当前工作区。
7. As an 实验人员, I want 用拖动手柄改变样本顺序, so that 自动排板按我的实验顺序生成。
8. As an 实验人员, I want 用拖动手柄改变基因顺序, so that 同一基因或同一内参的排序符合配液流程。
9. As a 键盘用户, I want 通过排序手柄的键盘操作上移或下移一行, so that 不依赖鼠标也能完成排序。
10. As an 实验人员, I want 拖动时看到源行和放置目标, so that 我能确认排序位置。
11. As an 实验人员, I want 拖动排序也进入撤销历史, so that 顺序调整可以立即恢复。
12. As an 实验人员, I want 中间当前孔板在左侧长列表滚动时仍可见, so that 我可以实时对照参数和板布局。
13. As an 实验人员, I want 中间当前孔板在右侧用量计算滚动时仍可见, so that 我可以同时核对孔数与试剂用量。
14. As an 实验人员, I want 孔板标签、状态和编辑工具与孔板一起保持可见, so that 我不必反复滚动查找操作。
15. As a 小屏用户, I want 页面回退到单列自然滚动, so that 独立滚动容器不会导致嵌套滚动困难。
16. As a 中英文用户, I want 撤销、排序和帮助文案随系统语言切换, so that 交互提示与其他界面保持一致。

## Implementation Decisions

- 使用独立的参数列表历史模型，历史快照仅包含样本与基因列表，不复制孔板布局。
- 参数历史保留最近 30 次有意义的列表变更。新变更会清空重做栈。
- 文本输入框获得焦点时，全局 Command/Ctrl+Z 不拦截，由浏览器处理文本撤销。
- 当焦点不在文本编辑控件中时，快捷键优先撤销参数列表变更；若无参数历史，再使用现有孔位编辑历史。
- 样本和基因列表共用一个稳定 ID 排序函数，将拖动源行移动到目标行位置。
- 使用浏览器原生拖放交互，不引入新的运行时依赖。排序手柄同时支持 Alt+ArrowUp 和 Alt+ArrowDown。
- 拖动排序后将布局标记为设置已变更，保留旧布局作对照，并要求重新生成后再确认或导出。
- 宽屏工作区使用固定视口高度和三个独立滚动区：参数、板布局和反应计算。
- 中间板布局区保留孔板横向滚动，不缩小孔位至不可读。
- 在中等和小视口上取消视口锁定和独立纵向滚动，恢复现有的纵向内容顺序。

## Testing Decisions

- 测试只通过参数历史与排序的公开函数边界观察行为，不测试 React 内部状态、私有函数或调用次数。
- 参数历史覆盖删除后撤销、撤销后重做、新分支清空重做栈和历史上限。
- 排序覆盖上移、下移、跨多行移动、相同位置无变更和无效 ID 无变更。
- 页面结构由现有 rendered-HTML 验收测试扩展，验证宽屏独立工作区所需的语义标识与拖动帮助文案存在。
- 视觉布局通过桌面与移动视口各一轮渲染验收，检查独立滚动、孔板可见性、焦点顺序和文案截断。

## Out of Scope

- 不改变 96/384 孔的自动排板算法、复孔连续规则或跨板内参重做规则。
- 不改变孔位手动编辑、平移、确认和 Excel 导出的业务规则。
- 不引入跨设备同步、服务器保存或多人协作。
- 不为手机引入新的复杂拖动库；手机仍保留键盘或辅助技术可访问的排序入口。
